Règles

  • Atteignez exactement la case 100 pour gagner.
  • Simple : +2 si réussi, −1 si échec. Moyen : +5 / −2. Compliqué : +10 / −5.
  • Panne : deux échecs consécutifs en mode Compliqué → vous ne pouvez plus jouer qu’en Simple jusqu’à une réussite.
  • Radars : cases 10, 20, … 90 — une question bonus ; en cas d’échec, recul de 2 cases (ralentissement).
  • Si une bonne réponse ferait dépasser 100, vous ne bougez pas.
